# Jarvis Backups

Jarvis Backups is a personal backup utility for its owner's Home Assistant and Docker services. It uploads encrypted recovery archives to the owner's Google Drive, verifies uploaded files, and maintains a limited set of recovery copies.

The utility runs on the owner's computer. It is not a public service and does not offer sign-ups. Its Google Drive permission is limited to files created by, or explicitly opened with, this application. It does not request access to Gmail, Google Photos, contacts, or unrelated Drive files.

These public pages contain only an explanation of the utility. Backup archives, account credentials, and recovery keys are private and are not published here.
